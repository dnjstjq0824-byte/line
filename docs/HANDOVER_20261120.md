## 3. 11-20에 들어간 것

### 3-1. 실서버 장애 수정 — `internal_error`
- 증상: lunotalk.com 로그인 화면에 `internal_error`, 같은 요청이 무작위로 500.
- 원인(실서버 로그로 확정): 서버 isolate가 첫 요청에서 시작한 `boot()`/`ensureSchema()` 약속을 캐시해 두는데, 그 첫 요청이 먼저 끝나면 Workers가 이후 모든 await를 거부("This promise was created by a request that has since ended"). 그 isolate는 재활용될 때까지 모든 요청 500.
- 고침: `bootInRequest()` + `ensureSchema()` 1회 재시도 — 실패한 캐시는 버리고 현재 요청에서 다시 한다. 테스트 `scripts/boot_retry.test.mjs`(수정 전 0/2, 후 2/2).
- **규칙: module-level에 캐시한 promise는 요청 사이에 공유하면 안 된다. 쓰려면 실패 시 버리고 재생성하라.**
