# 프로필 진입 및 사진 변경 보완

2026-11-05. 기존에는 아바타 메뉴 내부에 프로필 화면이 있었지만 사진 선택·저장 경로가 누락돼 있었다.

- PC 왼쪽 위 아바타를 키보드로 조작 가능한 버튼으로 변경하고 내 프로필을 직접 열도록 수정했다.
- 모바일 하단에 프로필 진입 버튼을 추가했다.
- 내 프로필에서 사진 변경/삭제를 제공하며, 이름·상태 메시지는 기존 프로필 편집에서 수정한다.
- JPEG/PNG/WebP 파일 최대 10MB를 브라우저에서 512px JPEG로 최적화한다. 서버는 허용 형식·파일 시그니처·256KB 상한을 검사한다. SVG 및 임의 외부 URL은 새 사진으로 받지 않는다.
- 기존 D1 users.avatar_url 컬럼에 저장한다. 테이블/컬럼 마이그레이션은 없다. GET은 D1 사진을 다시 조회하며 재로그인·새로고침 후에도 사진을 표시한다.
- 사진 변경 성공 응답 전에 D1 저장이 완료돼야 한다. 실패 메시지와 저장 중 버튼 비활성 상태를 제공한다.

검증: 실제 격리 로컬 Worker/D1 및 Edge 브라우저에서 신규 계정으로 업로드→JPEG 최적화→GET→다른 로그인 세션 GET→새로고침 표시→삭제→GET 빈 값 확인 PASS. 잘못된 외부 URL 400 및 미인증 업데이트 401 PASS. 모바일 하단 진입을 실제 클릭했다. [실행 기록](./profile-photo-qa.json). 캡처는 로컬 `.vscode/audit-20261105/profile-photo-{390,1440}.png`.

Node 회귀 검사 56 PASS, 웹 앱 6개 타입 검사·빌드 PASS. 실제 고객 계정의 운영 사진을 테스트 목적으로 변경하지 않았다. 프로필 공개 범위 제어는 아직 준비 중이며 사진 변경 완료와 구분한다. 다른 사용자 화면의 사진 실시간 갱신 및 Flutter 사진 편집은 이번 검증 범위에 포함하지 않는다.
