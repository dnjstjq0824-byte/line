# LUNO 실제 메신저 서비스 완성을 위한 잔여 작업 보고

기준일: 2026-11-05. 목적: 현재 코드·실행 증거를 기준으로 남은 구현, 외부 연동, 검증, 제품 결정을 분리한다. 이번 보고서 작성은 추가 기능 구현이나 신규 운영 배포를 의미하지 않는다.

## 1. 현재 판정

**일부 실제 동작이 가능한 개발 단계이며, 상용 메신저 완성 상태는 아니다.**

- 실제 로컬 Worker/D1/Durable Objects에서 메시지 저장, 두 소켓 수신, 재시도 중복 방지, since_sequence 복구, 503개 메시지 페이지 복구를 검사했다. 다른 isolate·서버 재시작·모든 장애 조건을 증명한 것은 아니다.
- 세션 저장·철회, 메시지/첨부 저장, 읽음 커서와 감사 저장 코드가 있다. 표나 API의 존재와 모든 사용자 흐름의 완성을 구분해야 한다.
- 웹 프로필 진입, 사진 변경·삭제·D1 저장·재로그인 유지 검사는 완료했다. Flutter 동등 기능, 타 사용자 화면의 실시간 갱신, 공개 범위 제어는 미완성/미검증이다.
- 운영에 소켓용 USER_HUB 바인딩이 있다. **소켓 전달 지속성과 대화 멤버십/업무 데이터 지속성은 별개다.**
- 외부 공급자가 없는 푸시/STT/Webhook 테스트/결제/정산은 명확한 오류를 반환하도록 수정했다. 기능 완료가 아니라 가짜 성공 제거다.
- Android 서명 AAB는 실제 빌드했다. iOS 프로젝트는 구성했다. 실기기 검증·공식 스토어 제출은 완료하지 않았다.
- 가장 최근 프로필 작업 배포 시 기록한 Worker 버전은 `7ffb5405-5ea9-4d02-8634-9b03d22f0088`이다. 이 보고서에서 운영 버전을 새로 조회하지 않았다.

증거: [진행 보고](./PROGRESS.md), [프로필 사진](./PROFILE_PHOTO.md), [실시간/권한 통합](./security-stage.json), [운영 Smoke](./production-smoke.json), [패키징](./mobile-packaging.json).

상태 표기: **부분 구현**=일부 코드/흐름 존재, **미완성**=확인된 공백 존재, **미검증**=증거 부족으로 동작 확정 불가, **외부 의존**=공급자/단말/자격증명 필요. 미검증을 미구현으로 단정하지 않는다.

F04는 코드에 근거한 우선 조사 사항이며, 이 보고서에서 운영 권한 우회를 실행하거나 재현하지 않았다. 최종 심각도와 영향 범위는 안전한 격리 환경에서 확정한다.

## 13. 최종 완료 판정

전체 완성도 %와 일괄 완료일은 현재 증거로 산정하지 않는다. 필수 기능별 요구사항·외부 의존·목표 용량을 확정한 뒤 추정해야 한다.

실제 메신저 최소 출시는 **임의의 신규 사용자들이 가입하고, 대화를 만들고, 메시지/사진을 주고받고, 앱·네트워크가 끊겨도 복구하며, 적절한 알림을 받고, 차단·로그아웃·기기 철회가 일관되게 적용되는 것**으로 검증한다. 여기에 현재 PO 범위의 실제 음성/영상 통화·모바일 실기기·공식 계정 및 운영 콘솔 검증을 더해야 전체 지시서 완료다.

가장 먼저 해결할 것은 **대화/멤버십과 업무 상태의 영구 저장, 명시적 역할 기반 권한, 실제 여러 기기·장애 상황의 전달/복구**다. 이 기반이 없으면 화면을 더 추가해도 안정적인 메신저가 되지 않는다.
