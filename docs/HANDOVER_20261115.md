### 서버 (`scripts/cf_worker.js`)

- `routeBotCommands()`: 허용목록에 있는 방에서 `/`로 시작하는 글(또는 봇 메시지에 단 답장)이
  봇 작업(`kind:'command'`)이 된다. 멘션이 있으면 그 봇에게만, 없으면 방의 모든 봇에게 간다.
  명령으로 처리된 글은 멘션 작업(`routeBotMentions`)을 만들지 않는다.
- 승인/거절(`…/decide`): 제안을 올린 쪽이 봇이면 `kind:'decision'` 작업이 생긴다.
  decision 메시지 metadata에 `proposal_message_id`가 들어간다.
- 러너 상태: `POST bot/jobs/claim` 본문의 `presence`를 `luno_bot_config`의 `presence:<botId>`에 적는다.
  방 멤버는 `GET conversations/:id/bots`로 읽는다(`ready` / `busy` / `offline`, 90초 무응답이면 offline).
  상태가 바뀌면 방 멤버에게 `bot.presence` 이벤트를 보낸다.
- 대화방 영속화: `luno_conversations`, `luno_conversation_members`를 런타임 스키마(`ensureSchema`)에 넣었다.
  그래서 `wrangler.jsonc`의 `DURABLE_CONVERSATIONS`가 `"true"`다. `scripts/direct_chat.test.mjs`의 핀도 이 조건으로 바꿨다.
- `wrangler.jsonc`: `LLM_ENABLED: "true"`. 허용목록과 킬스위치가 그대로 모든 작업을 막는다.
- `/download`: 추천 APK(arm64)를 릴리스 자산에서 받아 그대로 내려준다
  (`Content-Disposition: attachment`, `Cache-Control: no-store…`). 자산을 못 받으면 `/download.html`로 보낸다.
  `/app`, `/mobile`, `/apk`는 전처럼 `/download.html`로 간다.
- 테스트: `scripts/pc_agent_routing.test.mjs`(12개), `scripts/app_download.test.mjs`.

### 러너 (`tools/pc-agent`, Node 24, 의존성 0)

읽을 순서: `README.md` → `src/agent.mjs` → `src/muse.mjs`, `src/git.mjs`, `src/guards.mjs`.

- 명령: `/status /git /check /continue /dev /mkt /ask /retry /merge /stop /cancel /log /diff /usage /help`
- 작업은 `C:\luno-wt\<번호>` worktree의 `luno-auto/…` 브랜치에서만 한다.
  커밋·테스트·diff 검사·보고·병합 제안은 러너가 직접 한다. main은 폰에서 승인해야 fast-forward로만 바뀐다.
- 상태·비밀값은 저장소 밖 `%USERPROFILE%\.luno-agent\`에 있다. 그 폴더를 읽거나 고치지 마라.
- 테스트: `cd tools/pc-agent && node --test "test/*.test.mjs"` (18개, 가짜 Muse + 임시 git 저장소).

## 9. 실서버에 반영된 뒤 고친 것 (커밋 `f20b2bf`)

- **`wrangler.jsonc`의 `run_worker_first` 목록을 지켜라.** 목록이 있으면 목록에 있는 경로만 Worker로 간다.
  `/api/*`를 빼면 모든 API 호출이 정적 자산 계층에서 405로 끝난다(로컬에서 실제로 겪었다).
  Worker에 `/api/` 밖의 새 경로를 만들면 이 목록에도 넣어라. `scripts/app_download.test.mjs`가 핀으로 잡고 있다.
- `/download`는 정적 자산(`download.html`)이 먼저 응답하고 있어서 Worker 코드가 실행되지 않았다.
  위 목록으로 Worker가 먼저 받고, 안내 페이지(`/download.html`, `/app`, `/mobile`, `/apk`)는 Worker가 같은 자산을 읽어 준다.
- 웹 로그아웃: `POST auth/logout`을 부른다. 전에는 메모리에만 있는 기기 id로 세션을 지워서,
  새로고침 뒤에는 항상 "서버 세션 해제를 확인하지 못했습니다"가 떴다. 테스트 `scripts/web_logout.test.mjs`.
- 웹 채팅 입력창: 전송 버튼과 글자 수가 입력 상자 안 오른쪽 아래에 들어간다(`luno-v2.css` 맨 끝).
- 배포 후 점검(`scripts/post_deploy_gate.mjs`)의 "unknown api path 404s as json"은 **이번 작업 전부터 실패**한다.
  Worker는 `/api/v1/*`에서 인증을 먼저 보기 때문에 로그인 안 한 요청은 없는 경로에도 401을 준다(`f24719e`에서도 같다).
  그래서 `npm run deploy`는 배포가 성공해도 종료 코드 1로 끝난다. 점검 기대값과 Worker 동작 중 어느 쪽이 맞는지는 대표가 정한다.
- 대표가 PC 웹 화면 전체 배치가 불편하다고 했다. 웹 화면을 손댈 때는 캡처로 확인하고, 화면 단위로 나눠 고쳐라.
