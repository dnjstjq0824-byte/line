# 프로필·설정 디자인 추가 개선

2026-11-05. 사용자 후속 지시: Git 커밋 작업은 보류하고 개발 및 어설픈 디자인 검토·수정 계속.

- 설정 모달의 고정된 흰색 하단 바가 입력란을 가리던 문제를 제거했다.
- 프로필 편집을 설정 첫 위치로 배치했다. 이름·ID는 넓은 화면에서 두 열, 모바일에서 한 열이며 소개는 여러 줄 입력이다.
- 각 입력에 연결된 레이블, 저장 중 입력 잠금, 변경 없음/빈 이름 시 저장 비활성화, 인라인 저장 결과 및 오류를 추가했다. 저장 성공의 중복 전역 알림은 제거했다.
- 실패하면 입력을 유지하며 재시도할 수 있다. 설정 재진입 시 이전 결과 안내를 초기화한다.
- 언어 선택 버튼의 라이트·다크 기본/선택 상태에 의미 토큰을 적용했다.
- 신규 문자열은 ko/en 리소스에 함께 추가했다. 서버 계약은 변경하지 않았다.

## 검증

실제 로컬 Go 서버와 기존 격리 SQLite 검수 계정으로 PATCH /me 200을 확인했다. 변경 없는 상태의 저장 비활성화, 실제 브라우저 오프라인 전환에 따른 오류 표시, 연결 복구 후 재시도 200을 확인했다. 모의 API 응답은 사용하지 않았다.

## 전달 상태

이번 추가 수정은 커밋·푸시·배포하지 않았다. 사용자 보류 지시 직전 이미 실행 중이던 배포는 완료되었으며, 그 배포 소스는 2188e8f, Worker 버전은 17fe1eac-bd8c-4026-b2cc-395c9c9ebffe이다. GitHub 자동 배포는 저장소 CLOUDFLARE_API_TOKEN 시크릿 누락으로 차단되어 기존 로컬 인증으로 수행했다. 해당 배포에는 이번 프로필 추가 개선이 포함되지 않는다.

전체 서비스 디자인 전수 개선 완료를 주장하지 않는다. 네이티브 모든 화면 및 역할별 콘솔 인증 후 업무 QA 등 기존 미검증 범위는 남아 있다.
