# LUNO AI Translation & Live Captions Report

## 1. Multilingual Message Translation
- **Supported Locales**: Korean (`ko`), English (`en`), Japanese (`ja`), Thai (`th`).
- **Per-Message & Auto-Translate**: Users can toggle `AI 자동번역 ON` in the chat topbar or click the translate icon on individual speech bubbles. Translated text renders inside `.luno-ai-translation-box` with source/target language badges and retry controls.
- **Voice/Video Live Captions**: Real-time AI subtitle stream overlay (`.live-captions-box`) with explicit user consent notice during active WebRTC calls.
