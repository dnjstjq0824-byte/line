# 모바일 미구현 갭 감사 (2026-11-10)

**대상**: Build 3 APK와 동일 소스(HEAD) + 실서버 워커 계약. 사용자 제보 "구현 안된게 너무 많아"에 대한 직접 감사.
**방법**: 모바일이 호출하는 워커 endpoint 전수 실측(Node에서 워커 import·데모 로그인·호출) + 화면 코드 21종 전수 판독. 화면 탭 → 핸들러 → 세션 → 서버 순서로 추적했고, 깨진 것만 기록.
**범위 밖**: 관리자 콘솔 화면(일반 사용자 미노출 취급), Go 백엔드(모바일은 워커만 사용).

## P0 — 눌러도 안 되는 것 (7건)

1. **피드(VOOM) 목록이 항상 빔 + 게시가 항상 실패**
   `session.dart:201`은 `posts` 키를 읽는데 서버는 `videos`로 줌(`cf_worker.js:2991`). 게시도 `body`만 보내는데 서버는 `title` 필수(400 "제목을 입력하세요"). 실측: GET 키 불일치, POST 400/201.
2. **대화방 송금이 항상 실패(403)**
   `session.dart:602`가 `{conversation_id, amount, title}`을 보내는데 서버는 `to_user_id` 필수(`cf_worker.js:3036`). 올바른 형태로 재호출하면 정상 처리(402 잔액부족 = 유효한 검증). 모바일 페이로드 버그 확정.
3. **오프라인 동기화가 항상 터짐**
   `session.dart:353`이 `x['messages']`를 읽는데 서버는 `delta_messages`로 줌. null 캐스트 예외 → 에러 스트립 표시. 대화방 헤더 동기화 버튼.
4. **공식 채널이 항상 빔**
   `session.dart:200`은 `official_accounts`를 읽는데 서버는 `accounts`로 줌(`cf_worker.js:2325`). 홈 카운터 "0", `/channels` "등록된 공식 채널이 없습니다" 고정. 타일까지 고치려면 표시 키도 교체 필요(`display_name`→`name` 등, `channels.dart:38`).
5. **스토리 카드가 빈칸 + 게시 불가**
   카드는 `emoji/author_name/text`를 읽는데(`stories.dart:72`) 서버는 `author(객체)/body/bg`를 줌(`cf_worker.js:2972`). 게시 UI 자체가 없음(서버 POST 201 지원 확인).
6. **푸시 알림 없음(외부 연동 필요)**
   FCM/APNs 플러그인·토큰 등록 코드가 없음. 앱을 닫으면 메시지를 받을 방법이 없음. Firebase 프로젝트 + APNs 키가 있어야 착수 가능.
7. **그룹 대화 만들기 UI 없음**
   1:1은 됨(`startChat` 201 확인). 서버 그룹 생성도 201 확인. 화면에만 진입점이 없음(목록에 + 버튼 없음).

## P1 — 웹/LINE에는 있는데 앱에 없는 것 (8건)

8. **노트/일정/투표는 보기만, 만들기·투표·RSVP 없음** — 서버 쓰기 전부 201 확인. `chat_archive.dart` 읽기 전용.
9. **앨범/미디어 모아보기 없음** — 서버 GET/POST 확인. 웹 P0-4 서랍과 대응.
10. **라운지 행이 불능 + 개설/입장 없음** — 타일에 `onTap` 없음(`lounge.dart:32`). 서버 개설은 `name` 필드로 지원.
11. **파일 첨부 없음** — 보내기 UI 없음. 받은 파일은 텍스트로만 표시되고 다운로드 불가(`chat_room.dart:358`). 사진·음성·동영상은 됨.
12. **프로필 편집 불가** — 이름/상태/생일/사진 전부 읽기 전용(`profile.dart`). 웹은 PATCH 지원.
13. **친구 즐겨찾기/차단 토글 없음** — 서버 PATCH 지원, 웹 지원. 앱 UI 없음.
14. **QR 스캔 없음** — 챌린지/토큰 수기 입력만(`settings.dart:133`). 사실상 사용 불가.
15. **번역은 항상 실패 표시** — 엔진 미구성 503(서버 사유, 웹과 동일). 앱은 인라인 "번역 실패"로 정직 표시. 엔진 연동 전까지는 설정 문구 손질만 가능.
